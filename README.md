# Simple Tank Game

A browser-based 2D tank battle game built with **Next.js** and **React**.  
Fight against an AI-controlled enemy tank across multiple maps, collect power-ups, and use special weapons.

## Features

- Player vs AI tank combat
- Multiple maps: Open Arena, Maze, Fortress, and random Chaos mode
- Destructible / indestructible walls
- Power-ups: Health, Speed, Rapid Fire, Shield, Slow, Confuse, Missile, Bounce shots
- Homing missiles with lock-on
- Collision detection, game loop, and sound hooks
- Unit tests (Jest) and e2e tests (Playwright)

## Controls

| Action | Input |
|--------|--------|
| Move | `W` `A` `S` `D` |
| Aim | Mouse |
| Shoot | Left mouse button |
